# ReferenceData

Machine-readable factual tables that support `../COMMUNICATIONS_REFERENCE.md`.

## SSM_DTC_MAP.csv

616 Subaru SSM factual DTC mappings plus header. Columns identify format, current-bank address, history-bank address, bit, and code.

Provenance: generated for the OBDWorkbench SSM DTC probe from factual mappings in FreeSSM revision `1a0fa0934581b3383adfd2722050503695ca9dab`, especially `src/SSMFlagbyteDefinitions_en.cpp`. Descriptive FreeSSM prose is not copied into this table.

Original project provenance notes are summarized in `COMMUNICATIONS_REFERENCE.md`, Section 45.
